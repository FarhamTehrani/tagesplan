        Kurzbefehl einrichten

        Ein Kurzbefehl auf deinem iPhone liest deine Termine von heute bis 14 Tage voraus und überträgt sie an Tagesplan. Je nach iOS-Version können Bezeichnungen leicht abweichen.

        1. Schlüssel erzeugen

          Damit weist sich der Kurzbefehl aus. Ein neuer Schlüssel macht den alten ungültig.

          Der Schlüssel wird nur jetzt angezeigt. Trage ihn gleich in Schritt 6 ein.

        2. Kurzbefehl anlegen

          App Kurzbefehle öffnen, auf + tippen und den Kurzbefehl „Tagesplan Kalender“ nennen.

        3. Termine suchen

          Aktion Kalenderereignisse suchen hinzufügen und die Filter so einstellen:

          • Startdatum · ist heute
          • Filter hinzufügen: Enddatum · ist in den nächsten · 14 Tage
          • Oben Alle auf Beliebige umstellen, damit beide Filter zusammen gelten.
          • Limit ausgeschaltet lassen.

        4. Jeden Termin als eine Zeile

          Aktion Wiederholen mit jedem hinzufügen. Hinein kommt eine Aktion Text mit diesem Aufbau:

          Startdatum | Enddatum | Ist ganztägig | Kalender | Ort | Titel

          Jedes Wort ist eine Variable: über der Tastatur Wiederholungsobjekt antippen, einfügen, dann darauf tippen und die Eigenschaft wählen. Die Striche „|“ mit Leerzeichen tippst du selbst.

          Wichtig: Auf Startdatum tippen → Datumsformat → ISO 8601 und ISO 8601-Zeit einschließen einschalten. Dasselbe bei Enddatum.

        5. Zeilen zusammenfügen

          Unter „Wiederholung beenden“ die Aktion Text kombinieren hinzufügen: Wiederholungsergebnisse mit Neue Zeilen kombinieren.

        6. An Tagesplan senden

          Aktion Inhalte von URL abrufen mit dieser URL:

          Weitere Optionen aufklappen: Methode auf POST. Unter Header einen Eintrag: Schlüssel apikey, Wert:

          Anfragetext: JSON mit zwei Feldern vom Typ Text:

          • token → dein Schlüssel aus Schritt 1
          • events → Variable Kombinierter Text

          Zum Schluss die Aktion Benachrichtigung anzeigen mit Inhalte von URL hinzufügen. Dann siehst du, wie viele Termine übertragen wurden.

        7. Testen

          Den Kurzbefehl mit ▶︎ starten und den Kalenderzugriff erlauben. Die Antwort lautet z. B. „12 Termine übertragen.“ Danach hier im Menü Jetzt abgleichen.

        8. Automatisch ausführen

          In Kurzbefehle unten auf Automation → +:

          • Tageszeit, z. B. 6:00 täglich → Sofort ausführen → „Tagesplan Kalender“.
          • Zusätzlich App → Kalender → Wird geschlossen → Sofort ausführen. So kommen Änderungen gleich nach dem Bearbeiten an.
